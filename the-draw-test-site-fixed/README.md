# The Draw — Test Site

Standalone prototype of the new The Draw funnel.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite gives you.

## Build

```bash
npm run build
```

## Deploy

This is a Vite + React + TypeScript site. Push the contents of this folder to GitHub and deploy with GitHub Pages, Vercel, Netlify, etc.

## Important

This is a TEST/SANDBOX build. It does not connect to Whop, authentication, payments, or the production Tarot API.
